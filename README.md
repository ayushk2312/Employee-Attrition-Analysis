Employee Attrition Analysis & Prediction

Project Overview

This project analyzes employee attrition patterns and uses machine learning to predict whether an employee is likely to leave an organization.

The project combines exploratory data analysis, data visualization, and Logistic Regression to identify important factors associated with employee turnover.

Objectives

- Analyze employee attrition patterns

- Identify factors associated with employee turnover

- Visualize important HR trends

- Build a machine learning classification model

- Evaluate model performance

- Provide actionable HR recommendations

Dataset

The dataset contains:

- 1,500 employee records

- 17 original features

- Employee demographic, job, income, satisfaction, and work-related information

The target variable is:

- Attrition — whether the employee left the organization

Technologies Used

- Python

- Pandas

- NumPy

- Matplotlib

- Seaborn

- Scikit-learn

- Jupyter Notebook

Methodology

1. Generate and prepare employee data

2. Explore the dataset

3. Analyze employee attrition

4. Perform exploratory data analysis

5. Visualize important factors

6. Prepare data for machine learning

7. Train a Logistic Regression model

8. Evaluate model performance

9. Analyze important features

10. Provide business recommendations

Key Findings

- Overall attrition rate: **44.13%**

- Employees working overtime had an attrition rate of approximately **52.76%**

- Employees not working overtime had an attrition rate of approximately **36.48%**

- The 21–30 age group had the highest attrition rate at approximately **61.44%**

- Lower job satisfaction levels were associated with higher attrition

- Work-life balance was also associated with employee attrition

Machine Learning Model

A Logistic Regression model was developed to predict employee attrition.

Model Performance

- Accuracy: **62.33%**

- Precision for employees who left: **58%**

- Recall for employees who left: **52%**

- F1-score for employees who left: **55%**

Important Features

The strongest model features included:

1. Overtime

2. Job Satisfaction

3. Age

4. Years in Current Role

5. Work-Life Balance

6. Job Involvement

7. Distance From Home

Business Recommendations

- Monitor employees who frequently work overtime

- Improve employee job satisfaction

- Provide career development opportunities

- Focus retention efforts on younger employees

- Promote better work-life balance

- Use attrition-risk analysis to support HR decision-making

Project Outcome

This project demonstrates how Python, data analysis, visualization, and machine learning can be used to understand employee attrition and generate actionable HR insights.
